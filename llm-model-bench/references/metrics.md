# Метрики: что и как считать

## Распознавание речи

| Метрика | Как считать | Порог внимания |
|---|---|---|
| WER общий | Левенштейн по словам после нормализации (нижний регистр, ё → е, без пунктуации) | сравнение с текущей моделью |
| WER по значимым словам | то же без слов-паразитов и междометий (`scripts/wer_significant.py`) | главный показатель качества текста |
| Имена | доля имён из истины, распознанных точно (с учётом падежа – по основе) | любое ухудшение заметно людям |
| Числа, суммы, даты | доля чисел истины, совпавших в тексте (цифрами или словами после нормализации) | ошибка в сумме хуже десятка ошибок в словах |
| Термины | доля терминов из списка (латиница, бренды), записанных верно | для ИТ-встреч и отраслевой речи |
| Пропуски | покрытие (конец последней реплики против длины файла), паузы в тексте > 30 с при речи в звуке, слов в минуту | живая речь 130–170 слов/мин |
| Таймкоды | сдвиг начала слов относительно истины, медиана и 95-й процентиль | > 1 с – плеер «прыгает мимо» |
| Петля повторов | повтор одной фразы 3+ раз подряд | любой случай – отказ модели |
| Скорость | минут обработки на час записи, отдельно при 1, 3, 6 задачах одновременно | обещание людям строится от этого |
| Память | пик RSS, пик памяти видеокарты, рост от задачи к задаче | рост без возврата – утечка или арена |
| Цена | за час записи с комиссиями | |

## Разметка говорящих

| Метрика | Как считать |
|---|---|
| Число людей | найдено против истины на каждом эталоне (2/2, 3/3, 4/4; лекция – лектор + доля зала) |
| Слово → говорящий | доля слов истины с верным говорящим после сопоставления текста с истиной |
| Ошибки у границ | сколько ошибок в ±2 словах от смены говорящего (типичный механизм: граница слова попадает на начало реплики следующего человека) |
| Обрывки | «говорящие» с речью меньше 60 с на записи длиннее 20 минут |
| Стабильность | два прогона дают одинаковое число людей |

Проверка правил поверх разметки: таблица «эталон × правило вкл/выкл × число людей × доля слов». Правило выкладывается, только если ни один эталон не ухудшился.

## Итоги и извлечение (LLM)

| Метрика | Как считать |
|---|---|
| Схема с первой попытки | доля ответов, прошедших валидацию (zod, JSON Schema) без починки |
| Пустая болванка | ответ формально валиден, но поля пустые или без ссылок на фразы |
| Стабильность | разница в числе извлечённых пунктов (задачи, решения) между двумя прогонами на одном входе |
| Выдумки | сроки без фразы о сроке в тексте; решения и задачи без опоры; даты, которых нет |
| Дубли | одно действие разными словами; одно и то же в разных разделах итога |
| Исполнитель | доля задач с исполнителем, который действительно назван в тексте |
| Длина ответа | доля ответов, упёршихся в предел токенов |
| Задержка | секунды на вызов, медиана и максимум |
| Цена | за час записи (сумма вызовов на запись / длительность) |

Считай эти метрики до и после каждой правки промптов и постобработки на одном и том же наборе (несколько записей × несколько моделей × 2 прогона): так видно, что правка действительно убрала дубли и выдумки, а не сдвинула их в другое место.

## Имена говорящих

- Неверное имя – главная ошибка: человек видит чужое имя у своей речи. Цель – ноль неверных, даже ценой большего числа «Спикер N».
- Имя принимается, только если модель приводит доказательство из текста (самоназвание «меня зовут…» в начале фразы, обращение по имени и ответ именно этого человека), а код его проверяет.

## Слепая оценка людьми

- Шкала 1–10 по каждому ответу, плюс комментарий.
- Минимум 6–8 фрагментов, разные домены и длины.
- Среднее по каждому человеку отдельно, затем общее. Расхождение людей больше 2 баллов на фрагменте – разобрать вместе.
