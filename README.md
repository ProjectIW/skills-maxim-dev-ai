# Скиллы для Claude Code

Набор скиллов для Claude Code от Максима Дедяева – разработчика и технического директора команды АЙСПЕКТР.

Telegram-канал: [@maxim_ai_dev](https://t.me/maxim_ai_dev) – новые скиллы и разборы работы с ИИ в разработке.

## Что такое скилл

Скилл – папка с файлом `SKILL.md` и вспомогательными материалами. В начале `SKILL.md` указаны имя и описание: по описанию Claude Code сам понимает, когда скилл пригодится, и подгружает его инструкции в работу. Так повторяющиеся процедуры (дизайн-ревью, выбор модели, запуск SEO, ведение документации проекта) выполняются каждый раз одинаково и с учётом известных ловушек, а не с чистого листа.

## Установка

Скопируйте папки, в которых есть `SKILL.md`, в `~/.claude/skills` (для всех проектов) или в `.claude/skills` внутри проекта (только для него). Новая сессия Claude Code подхватит скиллы сама.

Bash (macOS, Linux, Git Bash):

```bash
git clone https://github.com/ProjectIW/skills-maxim-dev-ai.git
mkdir -p ~/.claude/skills
for d in skills-maxim-dev-ai/*/; do
  [ -f "$d/SKILL.md" ] && cp -r "$d" ~/.claude/skills/
done
```

PowerShell (Windows):

```powershell
git clone https://github.com/ProjectIW/skills-maxim-dev-ai.git
$dst = Join-Path $HOME ".claude\skills"
New-Item -ItemType Directory -Force $dst | Out-Null
Get-ChildItem "skills-maxim-dev-ai" -Directory |
  Where-Object { Test-Path (Join-Path $_.FullName "SKILL.md") } |
  ForEach-Object { Copy-Item $_.FullName $dst -Recurse -Force }
```

Чтобы поставить скиллы только в один проект, замените `~/.claude/skills` на `.claude/skills` в корне проекта.

## Требования для скриптов

Сами инструкции работают без установки чего-либо. Вспомогательным скриптам нужны:

- `antislop-design-pass/scripts/*.mjs` – Node.js 18+, пакет `puppeteer-core` и установленный Chromium (путь – в переменной `CHROMIUM`);
- `llm-model-bench/scripts/wer_significant.py` – Python 3.9+, только стандартная библиотека;
- `llm-model-bench/scripts/add-noise.sh` – bash и ffmpeg 5+.

## Как устроен скилл

```
имя-скилла/
  SKILL.md        имя, описание (по нему скилл срабатывает) и основная процедура
  references/     подробности: чек-листы, протоколы, метрики – читаются по ссылке из SKILL.md
  scripts/        готовые скрипты для проверок и замеров
  assets/         шаблоны: HTML для слепой оценки, robots.txt, llms.txt, скелет инструкции
```

`SKILL.md` держится коротким: в контекст попадает только он, а подробности подгружаются, когда до них доходит дело.
