# Чек-лист ревью дизайна

Пройди перед показом. Каждый пункт – да или нет. Любое «нет» исправь или объясни.

## Текст

- [ ] Нет средней точки (U+00B7) (проверка: `LC_ALL=C.UTF-8 grep -rnP '\x{00B7}' [ПАПКА_ИСХОДНИКОВ]`, допустимы только регулярные выражения и комментарии).
- [ ] Тире только «–», нет тире-разделителей в заголовках и подписях («Тариф – Рабочий» как разделитель заменить на «Тариф: Рабочий» или отдельную строку).
- [ ] Нет технического текста: названий моделей и поставщиков, кодов ошибок, «фрагмент N из M», английских служебных слов вроде «maxTokens» или «evidence».
- [ ] Нет пояснений к очевидному (подпись «Название – мы учтём его в итогах» под полем «Название» лишняя).
- [ ] Одна и та же сущность не повторяется в двух местах экрана.
- [ ] Нет обещаний, которых нет в коде (магазины приложений, интеграции, «данные не покидают страну», если есть запасной путь за рубеж).
- [ ] В примерах нет реальных ФИО: «Спикер 1–3», «Персона 1», «Имя Фамилия».
- [ ] Числа точные и проверенные; обещания скорости – только согласованные.
- [ ] Оценка времени ожидания с запасом, но не пугает: обещай чуть больше реального, а не вдвое.

## Форма

- [ ] Нет значков, стикеров, эмодзи, символов-заменителей значков (★ ＋ × ✓ → •).
- [ ] Нет текста внутри цветных фигур (бейдж, плашка, кружок с цифрой) и фигуры внутри фигуры.
- [ ] Нет трёх одинаковых карточек с одинаковой структурой, если содержание этого не требует.
- [ ] Нет градиентного текста, свечений, теней под каждой карточкой.
- [ ] Ссылка «Подробнее» – текстовая ссылка, не кнопка.
- [ ] Отдельная одинокая ссылка не висит над карточкой – она внутри карточки (иначе окно выглядит «развалившимся»).
- [ ] Настройки – одной строкой, без карточек и описаний.
- [ ] Свои компоненты: нет `<select>`, `<input type=date>`, `<datalist>`, `window.confirm`, `alert`, браузерных пузырей «Заполните это поле».

## Движение

- [ ] Каждая анимация отражает реальное событие (загрузка идёт по байтам, обработка по этапам), нет фейковых процентов и этапов.
- [ ] Переходы без прерываний: нет мигания при обновлении данных, нет скачков вёрстки.
- [ ] Фоновые анимации: не больше 30 кадров в секунду, половинное разрешение холста, пауза при скрытой вкладке; замер CPU сделан.
- [ ] `prefers-reduced-motion` уважается.
- [ ] `view-transition-name` ставится только на время перехода.

## Адаптив

- [ ] Снимки 390, 768, 1280, 1440, 1920×1080, 2560×1440 без горизонтальной прокрутки, лишних полей и чрезмерного увеличения.
- [ ] На телефоне кнопки не закрываются плашками (cookie, панель браузера); размер касания от 44 px.
- [ ] Мобильная правка не изменила вид на компьютере (сравнение снимков до и после).
- [ ] Safari (WebKit) открыт и проверен.

## Сборка

- [ ] Вычисленные стили прод-сборки совпадают с dev на ключевых элементах.
- [ ] Нет дублей свойств в одном правиле (минификатор может переставить `gap` и `row-gap`).
- [ ] Шрифты загружены локально, кириллица и ₽ рисуются.

## Согласование

- [ ] Видимые правки главной согласованы отдельно.
- [ ] Макет показан до кода (для лендинга обязательно).
- [ ] В отчёте названо, что не трогали.
