# SEO и GEO для статического сайта без сборки

Вариант для сайта из готовых HTML-файлов, без Next.js и сборщика.

## Генератор по реестру страниц

Один скрипт держит реестр открытых страниц (путь, title, description, тип, дата правки, картинка превью) и из него:

- переписывает `<head>` каждой HTML: title, description, canonical, og и twitter, `og:video`, JSON-LD одним графом (WebSite, Organization, продукты с ценами, FAQPage, статьи, хлебные крошки);
- пишет `robots.txt`, `sitemap.xml`, `llms.txt` с датой «Обновлено», `llms-full.txt`, RSS блога;
- отдаёт список сцен для картинок и роликов превью.

Правила:

- Новая страница – строка в реестре и запуск генератора. Если статьи блога собираются своим скриптом, он вызывает генератор SEO сам, чтобы новая статья не осталась без разметки.
- **Дата правки страницы – из git** (дата последнего коммита её файла) или проверяется при выкладке: ручные даты отстают.
- После выкладки – проверка разметки на ключевых страницах (canonical, og, JSON-LD). При переносе редизайна разметка легко теряется: она жила в старой странице, а перенос шёл по вёрстке.

## IndexNow из выкладки

Скрипт выкладки после переключения релиза отправляет только новые и изменённые адреса (сравнение с файлом уже отправленного), через `api.indexnow.org`. Ошибка не роняет выкладку: не принятое уйдёт при следующей. Ключ IndexNow – файл в корне сайта, в список «не удалять при чистке».

## Переезд адресов при редизайне

- 301 со старых адресов – **только по явному списку** в конфиге веб-сервера, без подстановки пути клиента. Правило с захватом пути (`/old/* → /{path}`) даёт открытую переадресацию: `/old/%5Cexample.com` уводит на чужой сайт.
- После выкладки проверяется каждый старый адрес (301 и куда) и случаи `%5C` и `//`.
- Адреса без завершающего слэша – либо 301 на адрес со слэшем, либо осознанное 404.
- Файлы подтверждения поисковиков и ключ IndexNow – в список исключений чистки при редизайне.

## Что включать в sitemap, RSS и llms-full

Перед первым включением пройди статьи и страницы с владельцем продукта списком «оставить / переписать / снять». Индексация усиливает и то, что лучше было бы переписать.
